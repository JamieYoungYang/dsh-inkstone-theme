# 砚 · 主题（dsh-inkstone-theme）

七套水墨色板，加一层字体与渐变，给 DeepSeek Harness 用。

**汝窑 · 赭石 · 松烟 · 青瓷 · 紫毫 · 宣纸 · 胭脂** —— 器物自带颜色，名字就是取色说明。

## 装完在哪看到

**设置 → 通用** 里多出四行：

| 行 | 作用 |
|---|---|
| 配色方案 | 七套色板，各含浅色与深色两版 |
| 字体 | 跟随色板 / 无衬线 / 衬线 / 等宽 |
| 强调色强度 | 克制 / 标准 / 鲜明 |
| 侧栏材质 | 跟随主题 / 跟随系统材质（macOS 桌面版） |

## 七套是什么

| 色板 | 画布 | 身份 |
|---|---|---|
| 汝窑 | 冷蓝 `#e9eefb` | 工作台，紧致直角 |
| 赭石 | 暖赭纸 `#e4cebe` | 衬线编辑感 |
| 松烟 | 常暗深绿 `#0a1d15` | 仪表盘，硬边（切明暗都是深色） |
| 青瓷 | 青绿 `#dceff0` | 清透 |
| 紫毫 | 淡紫 `#ebe5f7` | 柔和 |
| 宣纸 | 奶纸 `#f2ecdd` | 印刷感 |
| 胭脂 | 玫瑰 `#f4e0e5` | 明快 |

## 它改了什么，没改什么

- **改**：颜色令牌（138 个别名 token 全覆盖）、正文字体族、画布顶部渐变、侧栏底色与渐变端点。
- **不改**：布局、间距、圆角、组件结构 —— 那些属于 DSH 自己的设计系统，插件不碰。
- **已知限制**：侧栏与主区之间的分隔线由 DSH 写死，本插件在**检测到对应元素存在时**才隐藏它；DSH 改版后可能失效，失效的表现只是「分隔线回来」，不影响配色。

## 审计

```bash
node audit.mjs          # 142 个必需 token 全覆盖 + 1554 组对比度 + 边框上下限
```

发包前这套必须 0 失败。

## 发布

本机 `~/.npmrc` 默认指向华为云镜像（只读缓存），**发布必须显式指回官方源**：

```bash
npm login --registry https://registry.npmjs.org   # 只需一次
npm run audit                                      # 0 失败才发
npm run release                                    # = npm publish --access public --registry https://registry.npmjs.org
```

**插件 → 砚 · 主题 → 移除**。移除后回到 DSH 默认配色，字体与渐变一并还原。
